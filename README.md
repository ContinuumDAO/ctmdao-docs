<h1>ContinuumDAO</h1>

> Meet the ContinuumDAO

A trustless Secure Multi Party Computation node network called the Continuum and run worldwide by a DAO.

**Before git push:** run `./scripts/before-git-push.sh` or `npm run before-git-push`. This rebuilds `search-index.json` and fails if the index is missing or not committed — required so docs.continuumdao.org and Continuum node AI doc tools stay in sync.

**Deploy:** publish `search-index.json` at the site root (`https://docs.continuumdao.org/search-index.json`).
